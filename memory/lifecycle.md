# Agent Memory Lifecycle

## Memory Layers

```text
L0 Context
L1 Session Memory
L2 Project Memory
L3 Organization Memory
L4 Knowledge Memory
```

## Lifecycle

```text
Create
 ↓
Validate
 ↓
Store
 ↓
Retrieve
 ↓
Update
 ↓
Expire
 ↓
Archive/Delete
```

## Governance Rules

- 不保存无价值临时信息
- 项目状态隔离
- 敏感信息需要权限控制
- 长期记忆必须有生命周期
- 用户记忆、项目记忆、知识记忆严格分离
- 允许追踪来源和修改历史
