# Skill Development Standard

Every Skill should provide:

- SKILL.md
- manifest.yaml
- README.md
- examples
- tests
- resources

Manifest should describe:

- name
- version
- capabilities
- triggers
- inputs
- outputs
- dependencies
- risk level
- evaluation rules
- compatibility

Skill lifecycle:

Draft -> Review -> Stable -> Deprecated -> Archived

Core Skills are industry independent. Domain Skills provide optional extensions.
