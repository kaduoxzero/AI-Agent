# Skill Lifecycle Governance

管理 Skill 从创建到淘汰的完整生命周期。

## 生命周期

```text
Draft
 ↓
Validated
 ↓
Stable
 ↓
Deprecated
 ↓
Archived
```

## 状态说明

- Draft：开发中的 Skill
- Validated：通过基础规范检查
- Stable：可生产使用
- Deprecated：不建议新增使用
- Archived：历史版本归档

## 生命周期要求

每个 Skill 必须具备：

- Manifest
- Version
- Capability 定义
- Risk 等级
- Evaluation Case
